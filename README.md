# Reflectly – AI-Powered Personal Growth & Journaling App

Reflectly is a full-stack journaling and self-reflection platform designed to help users better understand their thoughts, emotions, and habits through structured writing and AI-driven insights.

## ✨ Features

* 📝 **Structured Journaling**

  * Simple, Gratitude, and Reflection-based entries

* 🤖 **AI-Powered Analysis**

  * Generates summaries, emotional tone, cognitive distortions, and reframing suggestions

* 📊 **Weekly Insights**

  * Aggregates user activity to surface patterns, trends, and suggestions

* 😊 **Mood Tracking**

  * Score-based mood check-ins with historical tracking

* 🎯 **Habit Tracker**

  * Daily tracking with streaks and calendar visualization

* ⏳ **Anti-Procrastination Tool**

  * Task breakdown and completion tracking system

* 🔐 **Authentication System**

  * Secure login/signup with form validation

---

## 🛠 Tech Stack

**Backend**

* Python
* Flask
* SQLAlchemy, Flask-Migrate
* PostgreSQL (production)

**Frontend**

* HTML, CSS (modular architecture)
* Jinja Templates
* Chart.js

**Infrastructure & Integrations**

* OpenAI API (AI insights generation)
* GitHub Actions (scheduled weekly insights)
* Render (deployment)

---

## 🧠 How It Works

* Users create journal entries using structured formats

* AI analysis is triggered on-demand to generate:

  * Summary
  * Emotional tone
  * Cognitive distortions
  * Reframing suggestions

* Weekly insights are generated by aggregating:

  * Journal activity
  * Mood data
  * Habit tracking

* The system identifies behavioral patterns and provides actionable feedback

## ⚙️ Setup Instructions

1. Clone the repository

2. Create a virtual environment

3. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

4. Set environment variables:

   * `SECRET_KEY`
   * `DATABASE_URL`
   * `OPENAI_API_KEY`

5. Run database migrations:

   ```
   flask db upgrade
   ```

6. Start the server:

   ```
   flask run
   ```
